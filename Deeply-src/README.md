# 🍉 Deeply

Фокус-таймер для Windows в духе Focus To-Do: помидоры заменены арбузами, а на грядке растёт арбуз, которого в конце съедает кот.

Написан на **Electron** (HTML/CSS/JS), интерфейс отрисовывается на видеокарте.

## Возможности

- **Задачи** на «Сегодня» и «Неделю» с оценкой в арбузах, отметкой выполнения, правкой и переносом между списками.
- **Таймер**: фокус, короткий и длинный перерыв. Длинный перерыв после каждых N арбузов, автостарт этапов, пауза при сне компьютера.
- **Статистика**: арбузы, минуты и задачи за сегодня, график фокуса за 7 дней.
- **Грядка**: арбуз растёт 100 минут фокуса. Когда он созреет, приходит кот, съедает его, сам становится арбузом и укатывается.
- **Кот «ВРЕМЯ РАБОТАТЬ!»** появляется, когда заканчивается перерыв.
- **Мини-виджет** поверх всех окон с полупрозрачным фоном Windows.
- **Музыка с YouTube**: ссылка на видео или плейлист, сама включается во время фокуса.
- **«Не беспокоить» Windows** включается на время фокуса.
- **7 тем**: Изумруд, Стекло (жидкое стекло в стиле iOS, сквозь окно виден рабочий стол), Арктика, Обсидиан, Персик, Вино, Ковёр. Можно поставить свою картинку на фон.
- Трей, режим «поверх окон», автозапуск с Windows, пробел = старт/пауза.

Данные хранятся в `%APPDATA%\Deeply\data.json`.

## Запуск из исходников

Нужен [Node.js](https://nodejs.org/) 20 или новее.

```bash
npm install
npm start
```

## Сборка установщика

```bash
npm run dist
```

Готовый установщик появится в `dist/Deeply-Setup-<версия>.exe`. Установка идёт без прав администратора, папку можно выбрать, ярлык на рабочем столе ставится галочкой.

## Структура

| Файл | Что внутри |
|---|---|
| `src/main.js` | Главный процесс: окна, трей, уведомления, хранение данных, «Не беспокоить», YouTube-плеер, автозапуск |
| `src/preload.js` | Мост между окном и главным процессом |
| `src/index.html`, `src/styles.css` | Разметка и стили основного окна |
| `src/app.js` | Логика: задачи, таймер, статистика, настройки, музыка |
| `src/garden.js` | Грядка и анимация кота (Canvas 2D) |
| `src/liquid.js` | Эффект жидкого стекла (SVG-преломление) для темы «Стекло» |
| `src/themes.js`, `src/icons.js` | Палитры тем и SVG-иконки |
| `src/mini.html`, `src/mini.js` | Мини-виджет |
| `src/cat.html` | Всплывающий кот |
| `build/installer.nsh` | Дополнения установщика (галочка ярлыка, очистка при удалении) |
