Таймер для работы по помидорам, только вместо помидоров арбузы.
Работаешь 25 минут, отдыхаешь 5, после четырёх заходов длинный перерыв. Задачи делятся на «сегодня» и «на неделю», у каждой можно указать, сколько арбузов она займёт.

Пока ты работаешь, на грядке растёт арбуз. Когда он созревает, приходит кот и съедает его. После этого кот сам становится круглым, как арбуз, и укатывается. Смысла в этом никакого, просто приятно.

Ещё кот напоминает, что перерыв закончился и пора работать. Уведомления Windows на время работы выключаются, музыку можно поставить с YouTube, а маленькое окошко с таймером держать поверх всех окон.

Работает только на Windows.
